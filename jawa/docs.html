SannSunner — Rayfield Docs

Custom Rayfield mod reference. Built-in elements + CreateImageBar + CreateGrid. Biar ga lupa wkwk.

Setup & Loadstring

Load the SannSunner modded Rayfield loader. Paste ini di atas script kamu.

lua
local RayfieldLibrary = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/X5Dermaster/RayField-Loader/refs/heads/main/rayfieldloader.lua"
))()

Download flow

External URL ga bisa langsung masuk ImageLabel.Image. Flow-nya: game:HttpGet(url) → writefile() → getcustomasset() → set ke ImageLabel. Semua di dalam task.spawn biar non-blocking.

Tip: Pass ImageUrl = "" waktu create, terus panggil :Set(url) setelah element ada — ini penting kalo URL-nya perlu di-fetch dulu (kayak Discord avatar yang butuh request ke API).
lua
-- Avatar dengan Title + Content
local avatarBar = Tab:CreateImageBar({
    Name         = "DiscordAvatar",
    ImageUrl     = "",  -- kosong dulu
    XSize        = 46,
    YSize        = 46,
    CornerRadius = 23,  -- lingkaran
    Title        = DataUser.DiscordUsername,
    Content      = "SannSunner Member",
})

-- Load async setelah element ada
task.spawn(function()
    getGameIcon(placeid)  -- panggil :Set() di dalam
end)

-- Runtime update
avatarBar:Set(newUrl, newTitle, newContent)

-- Logo game (tanpa title)
local gameImg = Tab:CreateImageBar({
    Name         = "GameLogo",
    ImageUrl     = "",
    XSize        = 64,
    YSize        = 64,
    CornerRadius = 6,
    Align        = "Center",
})

Gotchas

UIStroke dummy: setElementsVisible di Rayfield akses element.Title dan element.UIStroke langsung tanpa FindFirstChild. ImageBar harus punya TextLabel bernama "Title" dan UIStroke bernama "UIStroke" sebagai direct child, walaupun kosong/invisible.
Theme key: SelectedTheme.ElementBorder ga exist — yang bener SelectedTheme.ElementStroke.

KeyTypeRequiredDescription

Itemstable[]RequiredList item (lihat bawah)

Item properties

KeyTypeDescription
NamestringLabel + key buat :Get()
TypestringPer-item override: "Toggle" atau "Button"
CurrentValuebooleanState awal (Toggle only)
CallbackfunctionToggle: function(bool) — Button: function()
lua
-- Mixed types per item
local grid = Tab:CreateGrid({
    Name    = "Loadout",
    Columns = 2,
    Items   = {
        { Name = "Aimbot",    Type = "Toggle", CurrentValue = true,  Callback = function(v) end },
        { Name = "Teleport",  Type = "Button",                       Callback = function()  end },
        { Name = "ESP",       Type = "Toggle", CurrentValue = false, Callback = function(v) end },
        { Name = "Kill All", Type = "Button",                       Callback = function()  end },
    },
})

-- Runtime: get handle per item
grid:Get("Aimbot"):Set(false)
print(grid:Get("ESP"):Get())  -- current state

Layout gotcha

UIGridLayout + dummy Title: dummy Title TextLabel TIDAK boleh jadi direct child Grid (dia akan di-layout sebagai slot kosong). Fix: taruh UIGridLayout + semua Cell di inner Frame "GridInner". Grid outer cuma pegang UIStroke + Title buat setElementsVisible.

Notes & Gotchas

setElementsVisible requirements

Setiap custom Frame yang jadi direct child TabPage HARUS punya:

lua
-- 1. UIStroke bernama "UIStroke"
local s = Instance.new("UIStroke")
s.Name = "UIStroke"
s.Parent = MyFrame

-- 2. TextLabel bernama "Title"
local t = Instance.new("TextLabel")
t.Name              = "Title"
t.Text              = ""
t.Size              = UDim2.new(0,0,0,0)
t.BackgroundTransparency = 1
t.TextTransparency  = 1
t.Visible           = false
t.Parent            = MyFrame

-- 3. Attributes buat transparency target
MyFrame:SetAttribute("BackgroundTransparencyTarget", 0)
MyFrame:SetAttribute("UIStrokeTransparencyTarget",   0)
MyFrame:SetAttribute("TitleTextTransparencyTarget",  1)

Theme keys yang valid

KeyDescription
ElementBackgroundBackground element
ElementBackgroundHoverHover state background
ElementStrokeBorder warna (bukan ElementBorder)
TextColorWarna teks utama
ToggleColorWarna toggle ON

External image loading

ImageLabel.Image ga bisa load HTTP URL langsung. Wajib: game:HttpGet(url) → writefile(path, body) → getcustomasset(path) → set ke Image property. Semua di dalam task.spawn.

Platform detection

lua
local ok, platform = pcall(function()
    return UserInputService:GetPlatform()
end)

local isPC = UserInputService.KeyboardEnabled
         and not UserInputService.TouchEnabled

local isMobile = UserInputService.TouchEnabled
             and not UserInputService.KeyboardEnabled

if not isPC and not isMobile then
    warn("Platform tidak dikenali")
end
